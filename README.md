# Piccolo Amore Website

Statisches Grundgerüst für GitHub Pages.

## Domain
`piccolo-amore-ape.ch`

## Wichtige Ordner
- `assets/images/logo` – Logo-Dateien
- `assets/images/hero` – grosse Startseitenbilder
- `assets/images/gallery` – Galerie/Eventbilder
- `assets/images/content` – sonstige Inhaltsbilder
- `assets/videos` – Videos
- `assets/documents` – PDFs, Menükarten, Preislisten etc.
- `assets/icons` – Favicon/Social Icons
- `assets/fonts` – lokale Webfonts
- `assets/css` – Stylesheets
- `assets/js` – JavaScript
- `pages` – Unterseiten

## GitHub Pages
Repository erstellen, Inhalt hochladen und unter `Settings > Pages` den Branch `main` und `/ (root)` auswählen.
Die Datei `CNAME` ist bereits auf `piccolo-amore-ape.ch` gesetzt.
